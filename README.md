# 🚗 ParkSmart – Smart Parking Management System

## 📌 Project Overview

ParkSmart is a web-based Smart Parking Management System designed to make parking easier, faster, and more convenient. It allows users to register, log in, search for parking locations using an interactive map, check parking slot availability, and book parking spaces for cars and bikes.

The system provides a colorful, responsive, and user-friendly interface with parking details, booking status, and parking charges. It aims to reduce the time spent searching for parking spaces and improve the overall parking experience.

## 🎯 Project Objectives

- To help users find available parking spaces easily.
- To provide an interactive map for location search and navigation.
- To enable convenient booking of car and bike parking slots.
- To display parking availability and booking status.
- To provide digital payment and e-receipt interface features.
- To support booking cancellation and modification.
- To monitor parking occupancy and manage reserved slots.
- To reduce traffic congestion caused by searching for parking.

## ✨ Key Features

### 1. 👤 User Registration and Login
Provides a user-friendly interface for registration and login to access the parking management system.

### 2. 🅿️ Parking Slot Booking
Allows users to view available parking slots, select a preferred slot, and make a booking.

### 3. 🗺️ Live Parking Map and Navigation
Provides an interactive map where users can search for locations and view parking areas.

### 4. 🚘 Car and Bike Parking
Supports parking options for different vehicle types, including cars and bikes.

### 5. 💳 Digital Payment and E-Receipt
Includes a payment interface for displaying parking charges and generating booking receipts as part of the demonstration.

### 6. 🔄 Booking Cancellation and Modification
Allows users to manage their bookings by cancelling or modifying reservations.

### 7. 🔒 Reserved Slot Management
Displays reserved parking slots and helps distinguish booked spaces from available ones.

### 8. 📊 Parking Occupancy Monitoring
Shows parking slot statuses using clear visual indicators to help users identify available and occupied spaces.

### 9. 🎨 Attractive User Interface
Features colorful layouts, parking-related visuals, interactive buttons, and a responsive design for a better user experience.

## 🛠️ Technologies Used

- **HTML5** – Structures the web pages.
- **CSS3** – Provides styling, colors, layouts, and animations.
- **JavaScript** – Handles user interactions, booking operations, and dynamic updates.
- **Bootstrap** – Supports responsive layouts and UI components.
- **Local Storage** – Stores demonstration data and booking information in the browser.
- **Interactive Map** – Supports parking location search and map-based navigation.

## ⚙️ How the System Works

1. The user opens the ParkSmart website.
2. The user registers or logs in through the interface.
3. The user searches for a parking location on the map.
4. The system displays parking information and slot availability.
5. The user selects a car or bike parking slot.
6. The user confirms the booking and views the booking details.
7. The user can manage or cancel the reservation.
8. The system displays the updated booking status.

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or run it using the Live Server extension.
4. Explore the login interface, parking map, slot selection, and booking features.

**Note:** This project is a demonstration prototype. Features such as live occupancy, online payments, and persistent multi-user bookings require suitable backend services or external integrations if they are not already implemented.
